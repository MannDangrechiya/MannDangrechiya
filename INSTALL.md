# 🚀 Installation & Setup Guide

This guide walks you through cloning, setting up, and configuring this premium GitHub Profile repository for **Mann Dangrechiya**.

---

## 📋 Prerequisites

Before setting up your profile repository, make sure you have:
1. A **GitHub Account**.
2. A repository named exactly matching your GitHub username (e.g., `MannDangrechiya/MannDangrechiya` or `.github` repo).
3. **Git** installed on your local machine.

---

## 🛠️ Step-by-Step Installation

### Step 1: Create Special GitHub Profile Repository
1. Navigate to [GitHub New Repository](https://github.com/new).
2. Set **Repository name** to your exact GitHub username (`MannDangrechiya`).
3. Set visibility to **Public**.
4. Check **Initialize this repository with a README**.

### Step 2: Clone the Repository Locally
```bash
git clone https://github.com/MannDangrechiya/MannDangrechiya.git
cd MannDangrechiya
```

### Step 3: Copy Repository Structure
Copy the contents of this template into your cloned repository:
```text
.
├── README.md
├── INSTALL.md
├── CUSTOMIZATION.md
├── DEPLOYMENT.md
├── CHANGELOG.md
├── LICENSE
├── assets/

│   │   ├── hero-banner.svg
│   │   ├── typing-header.svg
│   │   ├── whoami-card.svg

        └── readme-sync.yml
```

### Step 4: Commit and Push
```bash
git add .

git push origin main
```
